# Spec: Telegram-бот + канал «бесплатные программы»

## Зачем
Канал — витрина бесплатных программ Павла. Бот — «магазин»: выдаёт программы только подписчикам канала (воронка) и сам сообщает в канал о новых версиях.

## Сценарии
### US1 (P1) — Получить программу
- Дано: человек нажал «Скачать» в посте канала или написал боту /start. Тогда: видит список программ.
- Выбрал программу → выбрал Mac/Windows → если НЕ подписан на канал: «Подпишись» + кнопка «Я подписался» → после подписки получает команду установки одной строкой и прямую ссылку на файл.
- Ссылка на программу из поста ведёт сразу к ней (t.me/бот?start=shepot).

### US2 (P1) — Автопост об обновлении
- Дано: на GitHub вышла новая версия (есть файлы и для Mac, и для Windows). Тогда: в течение ~10 минут в канале пост: название, версия, «что нового», кнопка «📥 Скачать бесплатно».
- При первом запуске бот не постит старые версии — только запоминает.

### US3 (P2) — Команды для Павла
- /post shepot — опубликовать пост о текущей версии вручную.
- /stats — сколько человек нажимали «скачать» (по программам).

## Граничные случаи
- Бот не админ в канале → проверку подписки пропускаем (не мешаем людям), Павлу — предупреждение.
- GitHub недоступен → пробуем позже, ссылку даём на страницу релизов.

## Требования
- FR-1 Список программ — в programs.json (добавить новую программу = добавить запись).
- FR-2 Работает на VPS как сервис (systemd), перезапускается сам.
- FR-3 Секреты (токен) — только в .env на сервере.
